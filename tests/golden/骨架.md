# 黄金测试集骨架

这份文档说明**题集怎么排、每个位置填什么、填到什么程度算完**。
格式细节见 [README.md](README.md)，这里只讲结构与配额。

跑 `python -m pipeline golden --check` 随时看进度。

## 一、规模目标

| 项目 | 目标 | 依据 |
| --- | --- | --- |
| 总题数 | **40 题**（可 30-50） | 方案 §8.1 |
| 正样本（问答） | 22 道 | 测检索与作答 |
| 正样本（选择） | 8 道 | **能机械判分**，是唯一能可靠发现「结论说错」的题型 |
| 负样本 | **10 道**（下限，不能少） | 测编造率，方案的红线要求 |

选择题定在正样本的 **1/4 左右**：它能直接判对错，性价比最高；
但全是选择题又测不出「开放式提问答得怎么样」，所以两类都要有。

## 三、两种题型的模板

### 问答题

```json
{"id": "q-ch04-01", "question": "叠加定理能不能用来叠加功率？为什么？", "negative": false, "expect_pages": [10, 11], "expect_points": ["功率与电流是平方关系，不是线性关系", "只能叠加电压和电流", "功率要用叠加后的总电流/总电压重新算"], "chapter": "第4章 电路定理", "source_doc": "slide-07", "notes": "", "status": "ready"}
```

### 选择题

```json
{"id": "c-ch04-01", "question": "下列关于替代定理应用条件的说法，哪一项是错误的？", "negative": false, "choices": ["原电路和替代后的电路都必须有唯一解", "替代后的电路不能有电压源回路", "替代后的电路可以出现电流源节点", "被替代的支路与电路其它部分应无耦合关系"], "expected_choice": "C", "expect_pages": [25, 26], "expect_points": [], "chapter": "第4章 电路定理", "source_doc": "slide-07", "notes": "", "status": "ready"}
```

**出选择题的四条硬要求**：

1. **四个选项都从课件原文里找**，错误选项用学生的**典型误解**（把"不能有电流源节点"改成"可以有"），这样才真能测出理解偏差；
2. **`expect_pages` 填答案依据所在页** —— 判分时会同时检查它有没有引用对页码；
3. 用**唯一答案**的问法（"哪一项是错误的 / 哪一项是正确的"），**不要出多选题**；
4. 选项长度尽量接近，别让最长的那个一看就是答案。

## 四、填写顺序（建议）

题集里现在有 **32 个待填槽位**（`status: draft`），它们的 `chapter`、
`source_doc`、`expected_pages` 已经按切块元数据预填好了，你只需要：

1. **去掉 `【待写】` 标记**，把 question 改成学生的大白话；
2. **补 `expect_points`**（这道题必须答到的 2-4 个结论）；
3. 选择题还要把 `choices` 写全、`expected_choice` 改成正确项；
4. 把 `status` 改成 `ready`。

**建议按这个顺序做**（由易到难，先拿到可用的回归能力）：

| 顺序 | 做什么 | 耗时 | 为什么先做 |
| --- | --- | --- | --- |
| ① | 把 8 道负样本确认下来 | 20 分钟 | 只改措辞、跑一次检索确认相关度低即可。负样本是**编造率的唯一来源**，价值最高 |
| ② | 补齐 5 道选择题 | 40 分钟 | 机械判分，能立刻发现"结论说错"这类问题 |
| ③ | 补齐 19 道问答题 | 2 小时 | 最费时间，但可以边填边用手头的课件页对照 |

## 五、什么算"填好了"

一道题填好的标准，是**它能在不看你笔记的情况下被别人判断对错**：

- 一个不了解这门课的人，拿着 `expect_pages` 翻到那几页，能确认「答案确实在这儿」；
- 一个了解这门课的人，看 `expect_points` 能判断「答到这几条就算对」；
- 选择题的四个选项**互斥且有且只有一个正确**。

不满足这三条，题集就会变成"看着有 40 题、实际测不出东西"。

## 六、四个常见坑

| 坑 | 后果 | 怎么避免 |
| --- | --- | --- |
| `question` 抄课件标题（"3.1 支路分析法"） | 测不出真实效果——学生会说"支路法咋列方程啊" | 用大白话，念一遍像不像学生会说的话 |
| `expect_pages` 填成"最终回答里会引用哪页" | 判分时错位 | 填**答案依据在哪一页** |
| 负样本挑得太离谱（"量子力学是什么"） | 系统很容易过关，测不出问题 | 挑课程内但资料没覆盖的；"课件讲到但没讲透"的更好 |
| 只出选择题 | 开放式提问完全没测 | 问答题至少占 3/4 |

## 七、每次改动后怎么用

```powershell
python -m pipeline golden --check              # 看进度、校验格式（免费）
python -m pipeline golden --only-retrieval    # 只测检索（最便宜，改检索参数时用）
python -m pipeline golden                     # 完整跑（改提示词/换模型后必须跑）
```

跑出来的四个数字就是你的**基线**。改动之后数字变差，就回滚；
变好就记进 git 提交信息。这套东西的全部价值就在这里。
