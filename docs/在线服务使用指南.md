# 在线答疑服务 · 使用指南

对应实施方案 §7 阶段 2。学生打开一个链接就能提问，回答带课件页码引用；
课件没覆盖时会先联网、再退回通用知识作答，**不会直接拒答**，但一定标明依据来源。


## 二、让学生访问：Cloudflare Tunnel（试点期首选）

原理：把本机的 8000 端口通过一条隧道暴露成一个公网 https 链接。
**不需要公网 IP、不需要备案、不需要买服务器**（方案 §6.2 的第二个办法）。

1. 注册 <https://dash.cloudflare.com>，登录后进 `Zero Trust` → `Networks` → `Tunnels`；
2. `Create a tunnel` → 选 `Cloudflared` → 起个名字（如 `seeq-tutor`）；
3. 按页面提示下载 `cloudflared.exe`（Windows），把页面给出的安装命令复制下来；
4. 在 `Public Hostname` 里填一个域名（你自己有域名的话），
   `Service` 选 `HTTP`、URL 填 `127.0.0.1:8000`；
5. 保存后，把那个 `https://xxx.yourdomain.com` 链接发给学生。

**没有域名**的临时办法（链接每次重启都会变，只适合自己测）：

```powershell
cloudflared tunnel --url http://127.0.0.1:8000
```

它会打印一个 `https://xxx.trycloudflare.com` 地址，直接发出去即可。

> 试点期（5-10 人）用 `trycloudflare` 就够了。
> 要长期稳定再用正式隧道 + 自己的域名。

## 三、学生看到什么

```
┌────────────────────────────────────────┐
│ 电路理论（上）· 课程答疑                  │
│ 我是这门课的助教，回答会尽量依据课件…       │
│ 匿名代号 [xh-2026-07]        [随机]      │
├────────────────────────────────────────┤
│ 为什么理想电流源不能开路？        ← 学生   │
│                                        │
│ 结论：理想电流源不能开路，因为…   ← 助教   │
│ [依据课件] 第 25、26 页  6.4 秒           │
├────────────────────────────────────────┤
│ [输入你的问题…]                  [发送]   │
│ AI 回答仅供复习参考…                0/300 │
└────────────────────────────────────────┘
```

四种回答形态（依据越往下越弱，学生一眼能看出该不该当成复习依据）：

| 形态 | 标签 | 含义 |
| --- | --- | --- |
| 课件依据 | `依据课件`（蓝）+ 页码 | 检索到了相关内容，回答带真实页码，最可信 |
| 网络补充 | `网络搜索·未审核`（黄）+ 来源链接 | 课件没有，但联网搜到了；需要学生点开核对 |
| 通用知识 | `课件未覆盖·通用知识`（灰） | 课件和网络都没有，模型凭自己的知识作答 |
| 转人工 | `需人工确认`（黄） | 只在模型故障时出现 |

后两种都会同时记进「知识缺口清单」，方便后续补资料。

课件依据（`kb`）的回答会把所引用的课件原页图片**插在提到该页的那一段后面**，
公式也会按数学符号渲染，不再显示成一串 LaTeX 代码。图片和公式渲染所需的前端库
已经打包在 `app/web/static/` 里，不依赖任何外部 CDN，断网也能正常显示。

## 四、接口说明

| 接口 | 用途 |
| --- | --- |
| `GET /` | 学生端页面 |
| `GET /api/config` | 标题、介绍、免责声明、字数上限 |
| `GET /api/health` | 健康检查（给隧道/监控用） |
| `POST /api/ask` | 提问 |

提问示例：

```powershell
$json = @{ anon_code = 'xh-2026-07'; question = '替代定理的适用条件是什么？' } | ConvertTo-Json -Compress
$bytes = [System.Text.Encoding]::UTF8.GetBytes($json)
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/ask' -Method Post `
  -Body $bytes -ContentType 'application/json; charset=utf-8'
```

追问会自动带上最近几轮对话。页面把历史放在请求的 `history` 字段里
（`[{"role":"user","content":"..."}]`），服务端只用来理解「那种」「它」指的是什么，
不会单独存一份聊天记录。像「不是，是那种通用的结点方程」这种追问，
会连同上一轮问题一起检索，不会因为句子太短被判成「课件没覆盖」。

返回：

```json
{"mode":"kb","source_level":"kb","source_label":"依据课件",
 "answer":"结论：…（第25-26页）","citations":[25,26,22,23],"sources":[],
 "handoff":false,"latency_ms":6398,"top_score":0.9964}
```

`mode` / `source_level` 取值：

| 值 | 含义 |
| --- | --- |
| `kb` | 用课件内容作答，`citations` 里是页码 |
| `web` | 用联网搜索结果作答，`sources` 里是来源 URL |
| `general` | 用模型自己的知识作答 |
| `handoff` | 模型故障，没答出来 |

`handoff` 只在这两种情况下为 `true`，其余都算正常回答。

### 想启用真正的联网搜索

默认没有配搜索服务，`web` 这一档会被跳过，直接走 `general`。
在 `.env` 里填**任意一个**即可（改完重启服务）：

```ini
TAVILY_API_KEY=tvly-xxxx      # https://tavily.com
BOCHA_API_KEY=sk-xxxx         # https://open.bochaai.com，中文资料更好
SEARXNG_URL=https://your-searxng.example.com   # 自建实例，需开 JSON
```

填好后访问 `/api/health`，`web_search` 字段会从 `off` 变成服务名。
注意：`.env` 里如果留着一个无效的 `TAVILY_API_KEY`（比如占位符），
日志会出现 `401 Unauthorized`，请求会自动回落到通用知识作答。

## 五、能调的东西都在配置里

`config/app.yaml`：

| 配置 | 作用 |
| --- | --- |
| `limits.max_question_chars` | 单个问题最长字数（默认 300） |
| `limits.asks_per_hour_per_ip` | 每 IP 每小时提问上限（默认 30，防误触烧钱） |
| `copy.title / intro / disclaimer` | 页面文案，可以改成你们习惯的口吻 |

`config/retrieval.yaml`：

| 配置 | 作用 |
| --- | --- |
| `min_rerank_score` | **最关键的闸门**：重排分低于此值就判"资料没覆盖"（默认 0.5） |
| `rerank_top_n` | 对召回的前几条做重排（默认 8） |
| `retrieve_top_k` | 向量召回条数（默认 20） |
| `allow_web` | 课件没覆盖时是否联网（默认 `true`，没配搜索服务会自动跳过） |
| `allow_general` | 联网也没有时是否用通用知识作答（默认 `true`） |
| `external.web_note / general_note` | 学生看到的依据标签文案 |
| `handoff_patterns` | 直接转人工的关键词（默认空：不再拦截"证明/综合题"） |

改完直接重启服务生效（配置在启动时读一次）。

## 六、隐私与边界（方案 §1.3 的硬约束）

| 约束 | 实现 |
| --- | --- |
| 不收集姓名学号 | 只要求 2-16 位字母数字代号；代号里出现中文会被拒绝 |
| 不存 IP | 限流只在内存里按 IP 计数，重启即清零，不落库 |
| 日志可追溯 | `qa_logs` 记问题、命中块、回答、模式、耗时、模型；`session_id` 关联匿名会话 |
| 学生看到免责声明 | 页面底部固定显示 `config/app.yaml` 里的 disclaimer |

**目前还没有做的**：学情报告、诊断题组、维护者后台（属于阶段 3、4）。
现在学生只能提问，看不到自己的历史，也没有登录。

## 七、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 页面打开但提问报 503 | 模型服务不可用。看终端里的报错，多半是密钥/余额/网络 |
| 一直转人工 | `min_rerank_score` 太高，或知识库没入库。先跑 `python scripts/check_db.py`，再跑 `python -m pipeline golden --only-retrieval` 看分数 |
| 学生那边打不开链接 | 隧道进程要一直开着；关掉终端链接就断了 |
| 回答很慢（10 秒以上） | 生成模型是推理模型，思考耗时；可换非推理模型或降低 `max_tokens` |
| 想限制只有本校能访问 | 在 Cloudflare 上加 `Access` 策略（邮箱白名单或一次性 PIN） |

## 八、上线前必做的验收

```powershell
python -m pipeline golden
```

要求：**编造率 0%**、检索命中率 ≥ 80%、选择题全对。
当前实测：编造率 0%、检索命中率 97%、选择题 8/8。

然后手工走一遍：

- [ ] 手机浏览器能打开链接、能提问
- [ ] 问一个课件里有的问题，回答带正确页码
- [ ] 问一个课件里没有的问题，明确说"资料没覆盖"，**不编造**
- [ ] 连续快速点发送，会被限流拦下
