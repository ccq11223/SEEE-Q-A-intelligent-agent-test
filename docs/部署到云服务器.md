# 部署到云服务器：固定链接、电脑关机也能用

目标：把答疑服务放到一台 24 小时开机的 Linux 服务器上，得到一个固定链接，
不再依赖你的电脑和 `trycloudflare` 临时隧道。

---

## 一、先买一台服务器

推荐配置（试点 5-30 人足够）：

| 项目 | 建议 |
| --- | --- |
| 厂商 | 阿里云 / 腾讯云「轻量应用服务器」 |
| 地域 | **香港或新加坡**（不需要 ICP 备案，访问 Supabase 也快） |
| 配置 | 2 核 2G、40GB 磁盘、Ubuntu 22.04 |
| 带宽 | 3M 以上 |

国内节点更便宜，但**绑定域名需要备案**；前期可以先用 `http://公网IP:8000` 访问。

买好后在控制台做两件事：

1. 记下公网 IP；
2. 在「防火墙 / 安全组」里放行 **8000** 端口（以后上 HTTPS 再放行 80、443）。

---

## 二、连上服务器并安装 Docker

在 Windows 的 PowerShell 里：

```powershell
ssh root@你的服务器IP
```

第一次连接会问 `yes/no`，输入 `yes`，再输入服务器密码。

登录后执行：

```bash
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
systemctl enable --now docker
docker --version
docker compose version
```

看到版本号就说明装好了。

---

## 三、把项目传上去

回到**你自己的 Windows PowerShell**（不要关掉服务器的 SSH 窗口），执行：

```powershell
cd 'D:\学习资料\学业指导中心事务\2023级学业指导中心\agent-code'
ssh root@你的服务器IP "mkdir -p /opt/seeq"
scp -r app pipeline config data/work deploy requirements-app.txt Dockerfile docker-compose.yml docker-compose.https.yml .env root@你的服务器IP:/opt/seeq/
```

`data/work` 里是 844 张课件原图，约 135MB，上传需要几分钟，属正常。

> `.env` 里有 API Key，只通过 SSH 传，不要提交到 GitHub，也不要发群里。

---

## 四、启动服务

回到服务器的 SSH 窗口：

```bash
cd /opt/seeq
docker compose up -d --build
docker compose ps
```

第一次构建会下载 Python 镜像和依赖，大约 3-8 分钟（已配置清华 PyPI 镜像）。

看日志：

```bash
docker compose logs -f --tail 100
```

看到 `Application startup complete` 就好了，按 `Ctrl+C` 退出日志（不会停服务）。

---

## 五、验证

浏览器或手机打开：

```
http://你的服务器IP:8000
```

健康检查：

```
http://你的服务器IP:8000/api/health
```

应该返回：

```json
{"ok": true, "course": "电路理论", "backend": "postgres", ...}
```

这个链接就是固定的，你的电脑关机也不影响。

---

## 六、换成 HTTPS 链接（推荐）

HTTP 能用，但浏览器的「复制诊断报告」按钮需要 HTTPS 才能工作，
而且发给同学 `https://` 更让人放心。

1. 买一个域名（几十元/年），在 DNS 里加一条 A 记录指向服务器 IP，
   例如 `tutor.example.com → 1.2.3.4`；
2. 在服务器的 `/opt/seeq/.env` 末尾加一行：

   ```ini
   DOMAIN=tutor.example.com
   ```

3. 重新启动（带 HTTPS 配置）：

   ```bash
   cd /opt/seeq
   docker compose -f docker-compose.yml -f docker-compose.https.yml up -d
   ```

4. 等 1-2 分钟，Caddy 会自动申请证书。打开 `https://tutor.example.com` 验证。

成功后可以把安全组里的 8000 端口关掉，只保留 80、443。

> 香港/新加坡服务器不需要备案；国内服务器绑定域名需要 ICP 备案。

## 七、日常维护

```bash
cd /opt/seeq

# 看状态
docker compose ps

# 看日志
docker compose logs -f --tail 100

# 重启
docker compose restart

# 停止
docker compose down
```

更新代码后重新构建：

```bash
docker compose up -d --build
```

服务器重启后容器会自动拉起（`restart: unless-stopped`），不用手动操作。

---

## 八、需要知道的边界

- 数据库仍然在 Supabase，服务器只负责跑网页和提供课件图片；
  所以服务器要能访问 `*.supabase.co`（香港/新加坡节点通常没问题）。
- 测评进行中的状态存在内存里；容器重启后，正在做题的学生需要重新开始测评，
  已完成的测评结果存在浏览器里，不受影响。
- 每小时每 IP 30 次的限流仍然生效，防止链接被转发后额度跑飞。
- 课件图片已经打进镜像；以后补资料时，重新上传 `data/work` 再 `up -d --build`。

---

## 九、成本大概是多少

- 轻量服务器：通常几十元/月，学生优惠会更低；
- 域名（可选）：几十元/年；
- 模型调用：按量计费，试点期每天几元量级，取决于提问次数。

先用最低配跑试点，确认 5-10 个学生的使用效果后再扩容，比较稳妥。

## 十、常见问题

**构建时卡在 `pulling python:3.12-slim`**

Docker Hub 在国内可能很慢。给服务器配一个镜像加速：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{"registry-mirrors":["https://docker.m.daocloud.io"]}
EOF
sudo systemctl restart docker
```

再重新 `docker compose up -d --build`。

**页面能打开，但提问报 503**

看日志：

```bash
docker compose logs -f --tail 100
```

多半是 `.env` 里的 Key 或 Supabase 连接有问题。可以在容器里跑一次自检：

```bash
docker compose exec app python -m pipeline stats
```

**改了配置不生效**

配置在启动时读取一次，改完要重启：

```bash
docker compose restart
```

**想换端口**

改 `docker-compose.yml` 里的 `"8000:8000"`，前面那个数字是服务器端口。
